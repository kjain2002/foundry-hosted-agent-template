Prompt vs hosted

The only real cost gap is the hosted-agent runtime — your container hosted by Foundry. Everything else (tokens, code-interpreter session, MCP) is the same.

Auto vs pass-ID

Same sandbox, same $0.03/session. Pass-ID is a functional workaround (file download + avoids RBAC 403), not a pricier tier. Cost delta ≈ $0.

Latency, not a VM

No VM you spin up. Cold start is a few seconds, once per session, then warm reuse for the hour — not the minutes Jay was worried about.

Bottom line for Jay: the code-interpreter container hack adds no extra cost or pricing tier over normal code interpreter — it's the same session either way. The single genuine cost difference between what we run now and a plain prompt agent is the hosted-agent runtime compute (needed to work around private-endpoint limits), and latency is seconds-per-session, then warm.

~$0.03 per code-interpreter session is the published Azure OpenAI / Foundry rate — confirm exact figures for your region on the Azure OpenAI pricing page. Hosted-agent runtime compute is billed on the CPU/memory size chosen at deploy time. Figures here compare cost structure, not a specific monthly bill.
